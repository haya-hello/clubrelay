可用连接方式

本机模式：运行中的 OpenAI 兼容接口，例如 http://127.0.0.1:11434/v1；模型名称填写接口实际支持的标识，不自动下载或启动模型。本机地址也可能是云端转发入口，实际处理位置以该服务为准。

本机接口需要凭据时，明确勾选发送密钥并填写属于该接口的 Key；未勾选时不发送密钥。

云端模式：仅支持 https://api.deepseek.com/v1 或 https://api.openai.com/v1。必须由负责人明确选择服务、配置凭据并授权资料。

Windows 下 API Key 加密保存在当前用户的本机数据目录，页面不会回显。环境变量 QINGLIAN_AI_API_KEY 优先于本机保存值。

更改设置会停止采用运行中的旧请求结果，并要求重新授权活动。关闭模型不会删除原件或历史分析。
